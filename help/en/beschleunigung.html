Finding the acceleration

Without acceleration, run time and simulation are wrong: on short moves an axis never reaches its rapid speed. As long as the machine says nothing (rapid or acceleration 0), the add-on uses fixed defaults: rapid 10 m/min, acceleration 1 m/s² per linear axis and 1 rev/s² per rotary axis – like a small or retrofitted machine. The “Machining” assistant estimates its time with the same values, so all strategies compare. A big machine is faster; enter its values (under “Edit machine” at the operating mode) and the time in the check window is its own. Three ways, from exact to rough:

Empty fields show the default used for the calculation in grey. Only the largest spindle speed has none: without it nothing limits the speed – it is on the rating plate or in the data sheet.

1. The control's machine data

Most exact. Read only, never change. Often only visible with a key switch or password; the passwords for changing them are with the machine builder – reading usually does not need them.

  • Siemens 840D sl (also with ShopTurn/ShopMill): operating area Commissioning → Machine data → Axis MD; choose the axis with Axis +/Axis −, Search for the number. MD32000 MAX_AX_VELO (rapid), MD32300 MAX_AX_ACCEL (acceleration, m/s² or rev/s²), MD32431 MAX_AX_JERK (jerk), MD36100/36110 POS_LIMIT_MINUS/PLUS (software limits); spindle: MD35100 SPIND_VELO_LIMIT (largest speed).
  • Fanuc: key SYSTEM → PARAM, type the number → NO.SRH. Parameters 1420 (rapid) and 1620 (rapid time constant in ms); spindle: 3741 (largest speed of the first gear range). Acceleration ≈ rapid ÷ time constant. Match the units: mm/min ÷ 60,000 gives m/s, ms ÷ 1000 gives s.
  • Heidenhain (TNC 620/640): key MOD → Code number. The code number for the user parameters is in the control's user manual. Rapid and acceleration are mostly in the machine builder's parameters – then the data sheet or the builder is quicker.
  • Haas: rapid and largest spindle speed are in the model's data sheet (haascnc.com, the machine's page, “Specifications”).
  • LinuxCNC: in the INI file per axis MAX_VELOCITY (in mm/s – times 60 gives mm/min) and MAX_ACCELERATION (in mm/s² – divided by 1000 gives m/s²); spindle: MAX_FORWARD_VELOCITY in section [SPINDLE_0].
  • Mach3/Mach4: Config → Motor Tuning: Velocity (units per minute) and Acceleration (units per s²).

Note: these numbers come from general knowledge, not from your machine's manual – check there if in doubt.

2. Manual or data sheet

Rapid speeds are almost always listed, acceleration rarely.

3. Measure it

Move a short distance s at rapid and take the time t – ideally with the control's trace/oscilloscope function, otherwise with a stopwatch over many repetitions. If the distance is so short that the axis never reaches rapid speed:

a ≈ 4 · s ÷ t²

Example: 20 mm in 0.2 s → 4 · 0.02 m ÷ (0.2 s)² = 2 m/s².

This is an approximation: jerk rounds off the ramps, so the measured value tends to be a little low.

Spindle

Instead of acceleration, use the run-up time: stopwatch from standstill to maximum speed.
