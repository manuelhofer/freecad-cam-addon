Tool and workpiece mounts

A mount tells the add-on where a tool sits or where a workpiece is clamped. From that it also knows which axes sit in the head and which in the table.

Adding a mount

  1. Add a local coordinate system (LCS) in the part – in the turret, the spindle head, on the chuck, on the table.
  2. Put its origin at the reference point: spindle nose, tool holder in the turret, chuck face, table centre.
  3. On a tool mount point its Z axis along the tool, from the tip to the mount – the way +Z of the machine moves the tool away from the workpiece. On a workpiece mount point it straight out of the clamping face.
  4. On a workpiece mount the LCS is the coordinate system of the job: its X axis points the way X of the job lies on the clamped part – on a table usually like X of the machine, in a lathe chuck from the spindle axis towards the tool.
  5. In the dialog click + Tool mount or + Workpiece mount – if the LCS is selected in the 3D view, it is used right away.

Driven tools

For driven tool stations choose the spindle that turns the tool under Driven by.

Turret

Best build the turret as its own assembly: disc plus one LCS per tool station. In the machine it hangs on the slide with one revolute joint; that joint gets the operating mode Turret.

  • Every station is a tool mount named P1, P2, …. Which tool sits there comes from the CAM job later.
  • Distribute stations … takes a first LCS and the number of stations and places the others evenly around the turret axis. Distributing again replaces the earlier distribution.
  • Turrets with mixed axial/radial stations: add stations one by one and set the number under Turret station. That field only appears for tool mounts whose LCS sits on a turret.
