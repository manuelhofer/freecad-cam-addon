Axes and operating modes

Every slider joint and every revolute joint of your assembly is listed. A joint only becomes an NC axis once it gets an operating mode with an NC name.

To try it out: if there is no assembly yet, “Edit machine” offers the button New machine …. You choose from the usual types, ready-made with axes, spindles and mounts: a lathe with Y axis (slant bed, main spindle S1/C1, turret T, each station a VDI30 mount on S3 – how a tool stands in it is up to its holder in the tool manager; the check panel shows the tools), a 3-axis mill (cross table X and Y, milling head Z) and three 5-axis mills: table/table (trunnion A with rotary table C), head/head (fork head A/B, fixed table) and head/table (swivel head B, rotary table C). The chosen one goes into a new document, and this dialog opens straight away. That way you see how a machine is built before you build your own. Next time the choice starts at the one loaded last.

The same choice is available at any time with the New machine … button in the toolbar. For the lathe you enter its dimensions there – bed slant, an inclined Y axis, travels, turret stations, speed (help there).

Suggest

In an assembly you built yourself, no joint has an operating mode at first. Suggest gives every joint without one an operating mode:

  • Slider joints Linear. The NC name comes from the joint's name when an axis letter stands on its own there (“X”, “X slide”, “Slide Z2” → X1, X1, Z2), otherwise from the direction: along X of the assembly → X1.
  • Revolute joints with “spindle” in the name a Spindle (S1, S2 …), with “turret” the Turret (T), otherwise Positioning – A, B or C, depending on the assembly axis it turns about.

If a name is taken, it counts on (X2). The values stay empty – the notes below say which are missing. Check the suggestions: on a lathe whose assembly lies differently from the machine, the letters taken from the direction are not always right. + Operating mode suggests the NC name the same way; typing replaces it. If your control names the axes differently – say C4 and S4 for the main spindle, C1 and S1 for the driven tools –, type that here: the program then calls them that way.

The operating modes

LinearThe axis travels. Slider joints only. Examples: X1, Z1, Y.
PositioningThe axis turns to an angle. Revolute joints only. Examples: C4, B1, A.
SpindleThe axis turns at a speed. Revolute joints only. Examples: S1, S4.
TurretThe turret indexes from tool station to tool station. Revolute joints only.

Several operating modes on one joint

A revolute joint can play several roles. The main spindle of a lathe is called S4 when it turns and C4 when it positions to an angle, for example. Add two operating modes to the same joint. The same goes for a turret that can move to any angle: Turret and Positioning.

Joints without an operating mode

That is allowed. Such a joint is adjusted by hand, e.g. a tailstock without an NC axis. The NC program does not know it; its position is set by hand later.

The values

  • Fields with a bold label are required: rapid traverse, speed.
  • Empty fields mean unknown – not zero. Enter what you know; the rest can be added later.
  • Units are those of data sheets and machine data: mm/min, rpm, m/s² (linear), rev/s² (rotary), seconds.
  • Rated power (kW) of a spindle – the continuous power (S1) from the rating plate. Plan roughing values limits the cutting power with it.
  • Travel from/to (Linear) and Swivel range from/to (Positioning) are the joint's limits (min/max) in the assembly – you change them right here. An empty field means: no limit. They are counted as on the joint, i.e. the position of the slide, not of the tool tip: 0 is the position the assembly was built in. The grey sentence below says how far the first tool station is from the workpiece station – also at the limits. Where the tip gets to with a particular tool is worked out by “Check on machine” using the tool length.
  • counts in diameter (Ø) (Linear) – for X on a lathe, when the control shows X as a diameter and expects it in the program. With the tick, X is shown doubled everywhere, with “Ø” in front: in the travel here, in “Move machine” and in the check window. You then also type the diameter, and the add-on's post processor writes X that way. Calculations use the radius; the joint keeps its limits as a radius.
  • Home position and Tool change (Linear) – where the axis is when the machine is at home or at the tool change, counted like the travel. If an axis has a home position, traversing in the check window starts and ends there; before every tool change the machine moves to the change position – first Z up (on a lathe X away from the part), then the other axes; back to the part the other axes first, then Z. Time and collision count these moves too. Empty: no home position (traversing starts at the first point of the path); the change position empty: as home.
  • Home and tool change – below the axes, the points of all linear axes once more in one place, one row per axis. Above them: Change point counts in MCS (machine coordinates, the default – like the travel, independent of workpiece and tool; “G53 G0” in the program, “G0 SUPA D0” on Siemens) or WCS (workpiece coordinates – the tool tip, from the job's zero point; “G0” in the program; axes without a value stay). Home always counts in MCS. “Write program …” goes there before every tool change and at the end – first the axis that pulls the tool away, then the others –, and so does traversing in the check window.

How to find the acceleration is explained in Finding the acceleration.

Showing

Hover over an axis and everything that moves with it lights up in the 3D view and moves back and forth once. That shows which axis it is and which way it travels. Afterwards everything is exactly where it was.
