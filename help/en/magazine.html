Magazines

The same number means something different on every machine: on one, T1 is a Ø 12 end mill, on the other a spot drill. That is why there are three levels:

  • Tool manager – all tools there are, in all cabinets.
  • Magazine – what is set up as tools in a machine's control: per tool the T number the program calls it with and, optionally, its name in the control (Siemens with tool management: T="name"). A mill knows no turning tools, a lathe other numbers.
  • Loading – which tools of the magazine currently sit in the tool changer or on the turret: “loaded on P5”. What is not loaded the operator has to put in before the run.

The window

  1. Open the tool manager, bottom left Magazines ….
  2. On the left are the machines, each with the number of its magazines – expand one to see its magazines below, ✓ at the one that applies.
  3. New creates a magazine – if a machine is selected on the left, for it (the name counts on: “… 2”); otherwise for the first machine in your list that has none yet. The machine must already be in the list (“Machines …”). There can be any number of magazines; one applies per machine (tick “Applies to this machine”). Copy makes a second setup of the same machine that applies only once you tick it.
  4. Pockets: how many the changer or turret has – “–” means: as the machine says (on a turret its stations).
  5. One tool per row: T, Tool from the tool manager, Name in the control (empty: by number), Loaded on (empty: not loaded). Add tool appends a row with the next free number, From the numbers takes all tools with a number from the tool manager, Remove takes rows out.
  6. Red at the bottom, what does not fit: a number twice, two tools on one pocket, a pocket that does not exist.
  7. Saved with OK or Apply of the tool manager.

A tool you delete from the tool manager also disappears from the magazines.

In the assistants

If the machine you choose in the “Machining (milling)” or “4-axis machining” assistant has a magazine, it applies to the numbers in the job:

  • The Cutter list shows the magazine's tools first – the loaded ones on top, with number and pocket (“T5 · P3”) –, the others below with “not in the magazine”. One from the magazine is preselected.
  • The program calls a tool with its T number from the magazine, not the one from the tool manager. On a turret it goes to the pocket it is loaded on.
  • A tool that is not in the magazine gets a number that is taken neither in the magazine nor in the job. Below, in yellow, it says that it still has to be set up in the control; Add to the magazine enters it (with the number it already has in the job, otherwise the next free one) and saves the tool manager.
  • What a job already has keeps its number.

Setup list, program, collision

  • The Tool loading window shows the setup list: for each tool of the job loaded, load it, set it up in the control – or red when the job calls it with another number than the magazine (an older job, a changed magazine). Numbers from the magazine renumbers the job accordingly.
  • The program header shows the same after each tool (“T5 … – loaded on P3”); the “Write program” window shows a yellow sentence for what to set up, load or renumber. With {werkzeug} in the tool change (Siemens T="{werkzeug}") the program writes the name in the control where one is entered.
  • On a turret the collision check also includes what the magazine says is loaded and the job does not use – it turns with the turret.
