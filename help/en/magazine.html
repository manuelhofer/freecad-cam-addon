Magazines

The same number means something different on every machine: on one, T1 is a Ø 12 end mill, on the other a spot drill. That is why there are three levels:

  • Tool manager – all tools there are, in all cabinets.
  • Magazine – what is set up as tools in a machine's control: per tool the T number the program calls it with and, optionally, its name in the control (Siemens with tool management: T="name"). A mill knows no turning tools, a lathe other numbers.
  • Loading – which tools of the magazine currently sit in the tool changer or on the turret: “loaded on P5”. What is not loaded the operator has to put in before the run.

The window

  1. Open the tool manager, bottom left Magazines ….
  2. New creates a magazine – for the first machine in the machine storage that has none yet. The machine must already be there (“Machines …”). There can be any number of magazines; one applies per machine (tick “Applies to this machine”). Copy makes a second setup of the same machine that applies only once you tick it.
  3. Pockets: how many the changer or turret has – “–” means: as the machine says (on a turret its stations).
  4. One tool per row: T, Tool from the tool manager, Name in the control (empty: by number), Loaded on (empty: not loaded). Add tool appends a row with the next free number, From the numbers takes all tools with a number from the tool manager, Remove takes rows out.
  5. Red at the bottom, what does not fit: a number twice, two tools on one pocket, a pocket that does not exist.
  6. Saved with OK or Apply of the tool manager.

A tool you delete from the tool manager also disappears from the magazines.
