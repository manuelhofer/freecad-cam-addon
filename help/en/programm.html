Write program

The addon's postprocessor turns a CAM job into the program for your control. It writes all active operations of the job in their order – the addon's and FreeCAD's own – and knows from the machine what a lathe needs differently. FreeCAD's postprocessors are built for milling machines; on a lathe with C axis and driven tools several things were missing there.

How to

  1. Select the job in the tree (or one of its operations), then Write program … in the CAM-Addon toolbar.
  2. Machine: what the postprocessor knows about the job's machine – lathe or mill, X as diameter, the name of the rotary axis (“C is called C4”), which stations are driven (“T1 → S3”). The job remembered its machine when it was checked on the machine or in the 4-axis assistant. Without a machine it writes as for a mill.
  3. Control: LinuxCNC, Siemens 840D, Fanuc, Haas or Mach3/Mach4. The job remembers the choice, so does the machine – for the next job on it, it is preselected.
  4. The preview shows the first blocks. Save writes the whole program to the file (suggested: next to the document, with the control's extension – .ngc, .mpf, .nc, .tap).

What it writes

  • Tool change – on a mill “T1 M6”, on a lathe as the control wants it: Siemens “T1 D1”, Fanuc “T0101”, Haas “T101”.
  • Spindle – “M3 S…” (left M4). On a lathe, though, M3 turns the part: a driven tool gets the command of its drive with the drive's number from the machine – Siemens “M3=3 S3=…”, Haas “M133 P…”, LinuxCNC “M3 $1 S…”.
  • C axis on and off – before the first path with the rotary axis and at the end: Siemens “SPOS=0” / “SPCOF”, Haas “M154” / “M155”.
  • X as diameter if the machine counts X that way (tick in “Edit machine”) – the paths compute the radius, the program shows twice that.
  • Rotary axis – with Siemens the NC name from the machine, a number with “=” (“C4=90.000”); otherwise its letter.
  • Feed – in paths with the rotary axis G93 (F is 1 ÷ minutes per block), then back to feed per minute: G94 on a mill, G98 on Fanuc and Haas lathes (there G94 is a facing cycle).
  • Coolant – as set at the operation (flood M8, mist M7), then M9.

Changing commands

Commands … opens the list of commands: program start and end, tool change, spindle, driven tool, C axis, feed, coolant. Each can be changed – some are decided by the machine builder, those are yellow (with Fanuc the driven tool and the C axis); the program then contains a comment about it. Placeholders: {t} tool number, {s} speed, {m} 3 or 4 (direction), {n} number of the drive; “|” separates lines. Changes apply per control to all jobs; Reset brings the defaults back.

Not yet

Look-ahead and smoothing as ticks per control (Siemens G642, SOFT …), controls without G93 (the feed computed so that the time is right), cylinder and polar transformation (TRACYL, TRANSMIT) – planned, see specification W-005.
