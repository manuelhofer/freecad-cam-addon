Write program

The addon's postprocessor turns a CAM job into the program for your control. It writes all active operations of the job in their order – the addon's and FreeCAD's own – and knows from the machine what a lathe needs differently. FreeCAD's postprocessors are built for milling machines; on a lathe with C axis and driven tools several things were missing there.

How to

  1. Select the job in the tree (or one of its operations), then Write program … in the CAM-Addon toolbar.
  2. Machine: choose the machine – any open one, even one not saved yet (“… – not saved”), and the remembered ones. Preselected is the one the job remembered when it was checked on the machine or in the 4-axis assistant; if it has none, the first open one. If the chosen one is in a file, the job remembers it. Below it says what the postprocessor knows: lathe or mill, X as diameter, the main spindle and its C axis (“main spindle S4, C axis C4”), which stations are driven (“T1…T12 → S1 (C1)”). Without a machine it writes as for a mill.
  3. Control: LinuxCNC, Siemens 840D, Fanuc, Haas or Mach3/Mach4. The job remembers the choice, so does the machine – for the next job on it, it is preselected.
  4. The preview shows the first blocks. Save writes the whole program to the file (suggested: next to the document, with the control's extension – .ngc, .mpf, .nc, .tap).

What it writes

  • Tool change – on a mill “T1 M6”, on a lathe as the control wants it: Siemens “T1 D1”, Fanuc “T0101”, Haas “T101”.
  • Spindle – “M3 S…” (left M4). On a lathe, though, M3 turns the part: a driven tool gets the command of its drive with the drive's number from the machine – Siemens “M1=3 S1=…” (drive S1), Haas “M133 P…”, LinuxCNC “M3 $1 S…”.
  • C axis on and off – before the first path with the rotary axis and at the end, with the number of the main spindle: Siemens “SPOS[4]=0” / “SPCOF(4)” (main spindle S4), Haas “M154” / “M155”.
  • X as diameter if the machine counts X that way (tick in “Edit machine”) – the paths compute the radius, the program shows twice that.
  • Rotary axis – the C axis of the main spindle, with Siemens its NC name from the machine, a number with “=” (“C4=90.000”); otherwise its letter.
  • Feed – in paths with the rotary axis G93 (F is 1 ÷ minutes per block), then back to feed per minute: G94 on a mill, G98 on Fanuc and Haas lathes (there G94 is a facing cycle).
  • Coolant – as set at the operation (flood M8, mist M7), then M9.

Main spindle and driven tools

A lathe with driven tools has two spindles, each with an S and a C: the main spindle turns the part (S) or positions it (C) – for milling it positions: “SPOS[4]=0”, then “C4=…” in the blocks. The tool drive turns the tool (“M1=3 S1=…”); its C axis only orients it and never appears in the path. Which spindle does what, the postprocessor tells from the machine: the spindle the tool stations hang on (“Driven by”) is the drive; the other one is the main spindle. The names are in “Edit machine”; “New machine …” asks for the numbers on the lathe.

To the tool change point the program moves with Siemens using “G0 SUPA D0 X… Z…” – in machine coordinates, without tool offset; that is also the example in the Siemens manual (job planning, tool change routine). Two other ways you enter under Commands … at “To the change point (MCS)”:

  • F_HOME – on a machine with ShopTurn: the ShopTurn cycle that moves to the tool change point set there. A command without {achsen} appears once before each tool change and at the end. Whether F_HOME knows your point in a plain G-code program (without a ShopTurn program header), check in the control's simulation.
  • G75 {achsen} FP=1 – “approach fixed point”: the tool change point from the machine data (MD30600); the values after the axes do not count.

Before the first run look at the program in your control's simulation: the commands for the C axis and the drive follow the Siemens manual; on the machine the builder decides some things differently.

Changing commands

Commands … opens the list of commands: program start and end, tool change, spindle, driven tool, C axis, feed, coolant. Each can be changed – some are decided by the machine builder, those are yellow (with Fanuc the driven tool and the C axis); the program then contains a comment about it. Placeholders: {t} tool number, {s} speed, {m} 3 or 4 (direction), {n} number of the drive, {h} number of the main spindle; “|” separates lines. Changes apply per control to all jobs; Reset brings the defaults back.
