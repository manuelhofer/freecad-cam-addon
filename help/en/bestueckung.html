Tool loading

This shows which tool from the tool manager sits in which turret station. The tool manager is your tool cabinet: shape, holder, cutting data. The loading belongs to the machine – two machines can be loaded differently.

Moving and unloading

  • For each station (P1, P2 …) pick a tool from the list.
  • A tool sits in at most one station. Pick one that is already elsewhere – it then says, for example, “– in P4” – and the other station becomes free.
  • “– free –” unloads the station. The tool stays in the tool manager and can go back into a station at any time.
  • Tool manager … opens the tool cabinet. What you save there is available here right away.

Stations you do not load

A station you do not load here holds the tool with its number from the tool manager: T3 sits in P3 – unless T3 already sits in another station. So nothing changes until you move a tool, not even on a machine from an earlier version.

In the program

On a turret the program calls the station: if T3 sits in P5, the program says T5. That is how the 4-axis assistant sets up the tool controller; its cutter list starts each cutter with where it sits (“P5 · T3 …”), otherwise a yellow sentence says it sits in no station. “Check on machine” compares: if a job calls a station that holds a different tool according to the loading – or none – a note says what sits there and where the right one is.
