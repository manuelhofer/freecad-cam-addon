Tool loading

Which tool sits in which turret station is set by each job itself – just as you set up the turret for an order. You store the machine once and load it for every job; it knows its stations, but no loading. A base job and its swivelled planes (3+2) are one program – they share one loading; the window says so.

The “Tool loading” window

  • Select the job in the tree (or one of its operations), then Tool loading in the CAM-Addon toolbar. The window opens the job's machine – the open one, otherwise the one it was last checked on.
  • In the 3D view the job's tools sit in the turret, each with its holder; every station shows its name (P1, P2 …). Look brings the turret into view.
  • For every station a list with the job's tools. Pick a tool for a station and it moves there; if another one was there, the two swap. A tool that sits elsewhere reads “– in P4”.
  • “– free –” exists only where nothing sits: every tool of the job needs a station.
  • Every move is one undo step in the job's document.

In the program

On a turret the program calls the station: a tool in P5 is T5 in the program. That is why the loading lives in the job's tool controllers – their number is the station, and their name follows when you move a tool (“T3 Roughing” → “T5 Roughing”). Program and loading can never drift apart.

New tools in the job

The 4-axis wizard puts a new tool in the station of its number from the tool manager if that is free in the job, otherwise in the first free one; its cutter list shows where in front (“P3 · …”). A tool already in the job keeps its station. Without a turret (say a mill with one spindle) the number from the tool manager applies.

Checking

If two tools of the job sit in one station – say because a controller was changed by hand –, “Check on machine” says so; the machine would take only one. This window shows the same sentence in red, and you move one of them.

Setup list – with the machine's magazine

If the machine has a magazine, the setup list is shown at the bottom: for each tool of the job, what to do at the machine – also on a mill without a turret.

  • grey “loaded on P5” – nothing to do;
  • yellow “not loaded – load it” (on a turret “load it on P3”) – it is in the magazine but not in the changer or turret;
  • yellow “not in the magazine – set it up and measure it in the control”;
  • red “T8 in the magazine” or “loaded on P4” – the job calls it with another number than the magazine says: the machine would take a different tool. Numbers from the magazine renumbers the job accordingly (on a turret: the pocket it is loaded on); the others keep their number if the magazine does not use it, otherwise they get a free one. One undo step.

What the magazine says is loaded on a station the job does not use is shown in the choice (“– free – (loaded per magazine: …)”) and translucent in the view – the collision check includes it.
