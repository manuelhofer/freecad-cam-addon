Move machine

One slider per axis: drag it or type a value, and the machine in the 3D view moves along – so you see whether the axes run the right way round, what moves with what, and where it gets tight. This is the basis for the simulation.

To try it out: without an assembly the command offers the button New machine … – to choose from a lathe with Y axis and turret, a 3-axis mill and three 5-axis mills (table/table, head/head, head/table), ready-made in a new document, ready to move.

The rows

  • Name – the NC name of the mode (e.g. X1, C4, T). Joints without a mode are shown with their name in the assembly – their position is also set by hand here. A spindle is listed under its positioning name (C4 instead of S4): turning here means positioning.
  • Slider and number field – mm for linear, degrees for rotary axes. Counted as in the assembly's joint: the position of the joint's second side relative to its first. That way the numbers match the limits. If an axis counts in diameter (tick at its mode, e.g. X of a lathe), the field shows “Ø” and twice the value – you then also type the diameter.
  • Limits – from the joint's limits (minimum/maximum). It doesn't go further. If it says “no limit”, one can be entered in the joint.

Turret

For a turret there is a choice of stations (P1 … Pn) on the right. Choose one, and the turret turns the shortest way until this station is where P1 was when the window opened – with 12 stations, P4 turns the turret by 90°. If a station is at that spot right now, the choice shows it, otherwise “–”.

Inclined axis: as in the program

If the machine has an inclined axis (in “Edit machine” under “Transformations”), there is a switch at the top:

  • as in the program (chosen first) – instead of the two slides, X and Y of the program are shown, square. For Y, both slides move, the way the control converts. Below it, in grey, where the slides are right now.
  • of the machine – one slider per slide, as when setting up by hand. Below it, in grey, where the tool is in the program.

How far Y gets depends on where X is: the compensating slide has to be able to move along. If one reaches its limit, both stop there, and a red line says which one – for example “Y cannot go further here: X1 is at its limit 150.00 mm.” So the working area is not a rectangle but a parallelogram.

What moves along

Everything behind the axis: its link and everything further out. When X1 moves, the turret moves along; when the cradle A tilts, the rotary table C tilts with it – and still stays at its angle.

OK, Cancel, Home position

  • OK keeps the position. One Ctrl+Z moves everything back.
  • Cancel moves everything back to where it was when the window opened.
  • Home position does the same without closing the window.

The position also stays when FreeCAD recomputes the assembly – the joints keep it.
