Machines

Machines … (menu CAM-Addon) shows your machines in one list: name, kind and file. A machine is a FreeCAD file with an assembly and the machine object from New machine or Edit machine. The list remembers where the files are – it does not copy them: if you change a machine, that counts at once.

How a machine gets onto the list

  • by itself when you save a file with a machine – also one you have just built with “New machine …”;
  • by itself when you check on it (“Check on machine”) or pick it in an assistant;
  • with Add …: choose a saved machine file.

The kind

The add-on reads the kind from the machine's axes: a lathe has a turret or a spindle that turns the part – behind it the stations and the extra axes (C, Y). Otherwise it is a mill: without a rotary axis 3-axis, with one 4-axis (A, B or C), with two 5-axis. Later the assistant's proposals follow from it – on the lathe a bar instead of a block.

The buttons

  • Add … – choose a machine file.
  • New machine … – build one; it comes onto the list as soon as you save it.
  • Edit (or double-click) – opens the file and “Edit machine”.
  • Find … – if a file is red (“not found”), it is no longer there: show where it is now, the entry follows.
  • Remove – takes the machine off the list; the file stays. If you save it again, it comes back.

The list is stored as maschinen.json in the folder CamAddon of your FreeCAD user data, like the tool management: it survives restart and update.
