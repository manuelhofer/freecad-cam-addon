Tools

Your tools are on the left, sorted by number; the values of the selected tool are on the right. Each line of the list shows the essentials at a glance: T3  End mill Ø 12 · z 3 · Carbide.

Add, copy, delete

  • New adds an end mill with the next free number. Enter the diameter first.
  • Copy takes the selected tool with all its values – handy for the same cutter in another diameter.
  • Delete asks first.

The fields

  • Number – the T number. Free to choose, each only once; if it is already taken, that is shown right below the fields.
  • Type – end mill, bull nose end mill (with corner radius), ball end mill, chamfer mill, drill.
  • Diameter and Flutes (bold) are needed for every calculation.
  • Flute length – the usable length of the cutting edge. It is the largest ap the tool can cut on its side, and later shows how much of the edge a use case actually uses.
  • Tool material – carbide or HSS.
  • Description – free text to find it again: manufacturer, order number, coating.

An empty number field means “unknown”.

Hand over to CAM

Save and hand over to CAM (bottom left) writes all tools as the tool library “CAM-Addon” into FreeCAD CAM – with their T numbers, diameter, flutes, flute length and tool material. In a job you add a tool and choose this library.

  • In the weekly build the cutting data goes along as suggestions: per use case vc and fz, with material and operation (full slot → slot, dynamic roughing → adaptive, finishing → profile …). In the tool controller, the feeds and speeds button then suggests them for the stock material. The stable version 1.1.3 only takes the tools.
  • Each hand-over replaces the previous one: tools that no longer exist here disappear from the library. Tools you created in CAM yourself are left alone.
  • Overall length (flute length + 2 × D) and shank (= D) are estimated – the tool manager does not ask for them (yet).

Cutting data into the job

The command Cutting data into the job in the toolbar sets spindle speed and feed of a CAM job's tool controllers – in one step that Ctrl+Z undoes. This works in every FreeCAD version, including 1.1.3.

  • The material comes from the job's stock if it has a material with a number (e.g. X5CrNi18-10 = 1.4301); otherwise the values for all materials apply. You can change it at the top.
  • One row per tool controller: the tool manager's tool behind it (from the library “CAM-Addon”, otherwise same T number and diameter), the use case – suggested from the controller's name (“T3 Dynamic roughing”) or the operation (Adaptive → dynamic, Pocket → roughing, Profile → finishing, Drilling → drilling) –, the resulting n and vf, and what is set now.
  • Plunging and ramping get a third of the feed rate, drilling the full one.
  • Step over and step down: The operations that use the tool controller get ae as step over (in % of D, rounded down) and ap as step down – if the use case fits them: Adaptive gets “Dynamic roughing” and “Roughing”, Pocket and Face “Roughing”, Slot “Full slot”. A Profile gets nothing – it is also used for cutting out, in a full slot, and the ap of another use case would be too much for that. The column “Step over · step down” shows beforehand what goes where; the checkbox below turns it off.

Opening up a hole or pocket

Plunge helically once to the step-down depth, then clear the level with a small ae and the full flute length – that is what the Adaptive operation does when its step down is the flute length:

  1. In the tool manager, add a Dynamic roughing use case for the cutter – for example with Plan roughing values… – and Save and hand over to CAM.
  2. In the job, add a tool controller with this cutter and name it so that the use case is in the name: “T3 Dynamic roughing”.
  3. Put an Adaptive operation on the hole or pocket, with this tool controller.
  4. Cutting data into the job → Apply. The tool controller gets n and vf, Adaptive the step over (e.g. 10 %) and the step down (e.g. 25 mm): it plunges helically to 25 mm once and then clears the level.

The helix plunge angle is set in the Adaptive operation; the cutter's manufacturer states how steeply it may plunge.

Saving

Like FreeCAD's preferences: OK saves and closes, Apply saves and keeps the window open, Cancel discards – and asks first if you changed anything.

The tools are stored in your FreeCAD user folder under CamAddon/werkzeugverwaltung.json and survive every update of the addon. The previous version is kept next to it as .bak.
